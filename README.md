# ❤️ Heart Disease Prediction using Decision Tree

## 📌 Project Overview
This project predicts whether a patient has heart disease using a Decision Tree Machine Learning model.  
It also analyzes the most important features influencing the prediction and visualizes the decision tree.

---

## 🎯 Aim
To build a Decision Tree model that predicts the presence of heart disease based on patient medical attributes and to analyze feature importance.

---

## 📊 Dataset
The dataset contains 300+ patient medical records with features such as:
- Age
- Sex
- Chest pain type
- Blood pressure
- Cholesterol
- Heart rate
- Other clinical measurements

Target Variable:
- 0 → No Heart Disease
- 1 → Heart Disease Present

---

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## ⚙️ Algorithm
- Decision Tree Classifier
- Feature Importance Analysis
- Model Evaluation using Accuracy Score

---

## 🚀 Project Workflow
1. Load dataset
2. Preprocess data (convert categorical variables)
3. Split dataset into training and testing sets
4. Train Decision Tree model
5. Extract and visualize feature importance
6. Select Top 5 important features
7. Retrain model
8. Evaluate accuracy
9. Visualize Decision Tree

---

## 📈 Results
- The model successfully predicts heart disease with good accuracy.
- Top important features were identified.
- Using Top 5 features reduced complexity while maintaining performance.

---
